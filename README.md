# Anti-Double-Click

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Маленькая утилита для Windows в трее, которая убирает **ложные двойные клики** мыши.

Если у вас «дребезжащая» кнопка мыши (дешёвые/изношенные мыши часто вместо одного клика отправляют два), программа перехватывает и гасит второй, лишний клик. Обычные клики и настоящие двойные клики проходят как раньше.

## Возможности

- Полный перехват ложных двойных кликов на уровне системы (глобальный низкоуровневый хук `WH_MOUSE_LL`)
- Работает с левой, правой и средней кнопками - каждая включается отдельно
- Порог фильтрации настраивается в меню (5-300 мс) - чем больше порог, тем агрессивнее фильтр
- «Пост-задержка» - игнорирование кликов в течение N мс после каждого нажатия (по умолчанию выключена)
- Защита от «удержания» - блок повторных нажатий, пришедших слишком быстро после предыдущего
- Синтетические клики (автоматизация, RDP, экранная клавиатура) не фильтруются
- Иконка в трее, счётчик заблокированных кликов в подсказке (обновляется на лету)
- Иконка восстанавливается сама после перезапуска Проводника
- Автозапуск при старте Windows (опционально)
- Защита от запуска второго экземпляра
- Настройки сохраняются в реестре: `HKCU\Software\AntiDoubleClick`

## Трей-меню

- **ЛКМ / ПКМ по иконке** - открыть меню
- **Выключить/Включить** - пауза фильтра
- **Порог** - интервал, в который второй клик считается ложным
- **Пост-задержка** - полное игнорирование кликов после каждого нажатия (0 = Выкл)
- **Своё значение...** - в любом из подменю можно ввести произвольное значение в мс (Порог: 1-1000, Пост-задержка: 0-1000)
- **Кнопки** - какие кнопки фильтровать: Левая / Правая / Средняя (по умолчанию только левая)
- **Автозапуск** - запуск вместе с Windows

## Как работает фильтр

Для каждой кнопки отдельно:

1. **Порог** - нажатие блокируется, если пришло раньше, чем через N мс после
   предыдущего **отпускания**. Это основной параметр.
2. **Защита от «удержания»** - нажатие блокируется, если пришло раньше, чем через
   30 мс после предыдущего **нажатия**. Если порог задан меньше 30 мс, берётся сам
   порог, поэтому малые значения работают именно так, как выбраны.
3. **Пост-задержка** - если включена, любые нажатия в течение N мс после отпускания
   игнорируются безусловно.

Когда нажатие гасится, соответствующее отпускание гасится вместе с ним - приложения
не получают «висящих» событий, и выделение или перетаскивание не срывается.

## Сборка

Требуется Windows 10/11, Visual Studio (2019+) с компонентом «Разработка классических приложений на C++» и CMake.

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Готовый файл: `build\Release\anti-double-click.exe`

Или просто скачайте готовый exe из вкладки **Releases**.

## Использование

1. Запустите `anti-double-click.exe` - программа свернётся в трей.
2. Если ложные клики остались - увеличьте **Порог** (например, 30-80 мс).
3. Если стали глотаться настоящие двойные клики в проводнике - уменьшите **Порог** и/или отключите **Пост-задержку**.

## Важно

- Программа перехватывает ввод мыши **по всей системе**, пока она запущена.
- **Окна с повышенными правами не фильтруются.** Windows не позволяет процессу с
  обычными правами перехватывать ввод в окнах, запущенных от администратора
  (Диспетчер задач, редактор реестра, установщики). Если фильтр нужен и там -
  запускайте программу от имени администратора.
- Антивирусы иногда ругаются на низкоуровневые хуки - это нормально для подобных утилит.
- Выход: **ПКМ по иконке → Выход**.
